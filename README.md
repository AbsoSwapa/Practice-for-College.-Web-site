# Сайт
Этот сайт имеет при себе 3 готовые 3д модели что размещены на сайте, для их детального просмотра. Сделано оно используя библиотеку Three.js для интеграции 3д моделей на сайт
Сделано оно для компании по сантехники, поэтому модели временные что бы будущие владельцы могли их использовать

###Установка
Установка в своем роде очень простая. Нужно только иметь при себе OpenServer. 
Берем папку test.local и вставляем в папку domains корневого каталога программы. 
После при открытии OpenServer у вас будет возможность использовать данный сайт

##Использование
Вы видите 3д модели сайта снизу и поцентру. Их можно прокручивать 2-мя способами, с помощью мышки и с помощью ползунков что вы видите сверху, по оси x, y и z
Так же вы можете приближать модели ближе или дальше от экрана
Слева видно большие кнопки "Добавить" и "Удалить". Данные кнопки позваляют добавлять к существующим моделям новые из вашего проводника и удалять их

###Структура проекта
- `/test.local/index.html`: исходный файл со всем кодом сайта
- `/test.local/css.css`: файл для внешнего дизайна сайт
- `/test.local/pencil.glb`:  3д модель карандаша
- `/test.local/skybox_minecraft_daylight.glb`: 3д модель шара
- `/test.local/svetilnik.glb`: 3д модель фонарного столба
